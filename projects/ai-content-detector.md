# AI Content Detector

Веб-приложение для определения AI-генерированного контента в фото и видео.

## Описание

Приложение позволяет загружать изображения и видео файлы и определять, являются ли они созданными с помощью искусственного интеллекта или реальными. Использует машинное обучение для анализа статистических признаков и паттернов в контенте.

## Технологии

### Backend
- **FastAPI** - REST API фреймворк
- **PyTorch** - ML фреймворк для детекции
- **OpenCV** - Обработка видео и извлечение кадров
- **Pillow** - Обработка изображений
- **NumPy** - Математические операции

### Frontend
- **React** - UI библиотека
- **Vite** - Сборщик проекта
- **React Dropzone** - Загрузка файлов с drag & drop
- **Axios** - HTTP клиент

## Основные возможности

- ✅ Определение AI-генерированных изображений
- ✅ Определение AI-генерированных видео (frame-by-frame анализ)
- ✅ Drag & drop загрузка файлов
- ✅ Визуализация результатов с confidence score
- ✅ Поддержка множества форматов (JPG, PNG, MP4, AVI и др.)

## Архитектура

Приложение состоит из двух частей:
- **Backend API** (FastAPI) - обработка файлов и ML детекция
- **Frontend** (React) - пользовательский интерфейс

## Особенности реализации

1. **Гибридный метод детекции** - комбинация статистических признаков и ML модели
2. **Анализ видео** - извлечение ключевых кадров и агрегация результатов
3. **RESTful API** - стандартизированный API для интеграции
4. **Адаптивный дизайн** - работает на всех устройствах
