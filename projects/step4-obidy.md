# 4 шаг · Обиды (step4-obidy)

## Описание

Android-приложение для инвентаря **обид** по **4 шагу** 12-шаговой программы АН. Локальное хранение данных (Room) + **AI-консультант** (голос/текст через Vapi) со сценарной воронкой А→Б→В и 13 вопросами.

**Тип:** мобильное AI-приложение (Android)  
**Роль в портфолио:** пример интеграции LLM в продуктовый UX (цифровой помощник для самоанализа)

## Технологии

- **Kotlin**, Jetpack Compose, Room, Navigation
- **Vapi** — голосовой и текстовый AI-ассистент
- Промпт-инжиниринг: system prompt, воронка диалога, контекст инвентаря
- Локальная бизнес-логика воронки (`LocalFunnel`) + ephemeral assistant

## Основные возможности

- Список обид с прогрессом заполнения
- Категории: люди / учреждения / концепции
- Ситуации, типы, заметки для разбора со спонсором
- Импорт табличных данных
- AI-ассистент с контролем шага воронки и безопасными ограничениями (не заменяет спонсора)

## Особенности реализации

1. **AI-продукт, а не «чат ради чата»** — ассистент ведёт по методике, а не отвечает произвольно
2. **Контекст приложения в промпте** — шаг воронки, категории, сводка инвентаря
3. **Приватность** — данные инвентаря на устройстве; ключи Vapi вне репозитория (`local.properties`)
