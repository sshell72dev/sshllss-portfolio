# Situation - Telegram-бот для ежедневной рефлексии

## Описание

`Situation` - Telegram-бот на Python для сохранения ситуаций по дню, заметок и напоминаний с последующей AI-проработкой. Проект помогает пользователю фиксировать события, проходить пошаговый самоанализ, получать рекомендации и экспортировать результат сессии в удобном текстовом виде.

## Технологии

### Backend
- **Python** - основной язык разработки
- **python-telegram-bot** - Telegram Bot API и обработка сценариев
- **SQLite** - локальное хранение сессий, анкет и кэша
- **OpenAI-compatible API** - генерация разборов, рекомендаций и вопросов
- **python-dotenv** - загрузка конфигурации из `.env`

### Архитектура и инфраструктура
- **Polling / Webhook** - два режима запуска бота
- **JSON** - хранение приватных AI-промтов вне публичного репозитория
- **Pytest** - тесты для ключевой логики

## Основные возможности

- ✅ Сохранение ситуаций, заметок для самоанализа, напоминаний и обычных заметок
- ✅ Пошаговая проработка ситуации через индивидуальные AI-вопросы
- ✅ Генерация AI-разбора и практических рекомендаций
- ✅ Анкета пользователя с контекстом для персонализированных ответов
- ✅ Экспорт завершённой сессии в текстовом формате
- ✅ Кэш ответов AI и защита от повторных запросов
- ✅ Режимы `polling` и `webhook` для разных сценариев деплоя
- ✅ Разделение публичного кода и приватных промтов

## Особенности реализации

1. **Сценарный Telegram-бот**
   - Меню, кнопки и обработка пользовательских состояний
   - Отдельные сценарии для записей, анкеты и сессий

2. **AI-проработка ситуации**
   - Генерация краткого разбора
   - Практические рекомендации по ситуации
   - Автоматическая генерация вопросов для самоанализа

3. **SQLite-хранилище**
   - Сессии, ответы и настройки пользователя
   - Кэширование AI-ответов
   - Ограничение количества AI-запросов в день

4. **Безопасная публикация исходников**
   - Приватные конфиги и промты вынесены из публичного репозитория
   - Локальные IDE/серверные настройки не публикуются
