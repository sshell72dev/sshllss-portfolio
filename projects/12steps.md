# 12 шагов (12steps)

## Описание

Android-приложение для работы по **12 шагам**: дневник по Руководству, ежедневный самоанализ и **электронный психолог** с живым диалогом. Развилось из инвентаря обид [`step4-obidy`](step4-obidy.md) — блок 4 шага остался внутри, без потери прежнего UX.

**Тип:** мобильный AI-продукт (Android) + Python-бэкенд  
**Роль в портфолио:** полный цикл AI-продукта — клиент, LLM-сценарии, админка, монетизация

## Технологии

- **Kotlin**, Jetpack Compose, Room, Navigation, WorkManager
- **Python** — API анализа и психолога (`/api/v1/analyze`, `/api/v1/psych`), админка, Premium
- **DeepSeek** (flash / pro), кэш ответов, промпт-инжиниринг
- **Vapi** — голосовой консультант в инвентаре обид
- **ЮKassa** — разовые платежи Premium (самозанятый / НПД)
- Локальные данные: JSON / SharedPreferences / Room на устройстве

## Основные возможности

- Дневник 12 шагов: Шаг → Глава → Точка (`categories-tree.json`), помощь и анализ ИИ
- 4 шаг: инвентарь обид, 13 вопросов, импорт, голосовой ассистент
- Самоанализ: 10 шаг, mini, шаги 1–3, 12 вопросов, чистый день; история и шаринг
- Электронный психолог: онбординг, ситуация в моменте, разбор / рекомендации / проработка, темы, напоминания, голос
- Единые имя, анкета и портрет «Моя личность» для всех разделов
- Защита входа паролем и отпечатком
- Premium: paywall → ЮKassa → webhook entitlement по `device_id`

## Особенности реализации

1. **Один продукт, три сценария** — журнал, самоанализ и психолог делят профиль, чтобы ИИ не переспрашивал имя и контекст
2. **AI как методика, не чат** — сценарии дневника и психолога завязаны на шаги программы; ассистент не заменяет спонсора и группу
3. **Приватность** — записи на устройстве; ключи Vapi / API / ЮKassa вне репозитория
4. **Монетизация вне стора** — ЮKassa для РФ/НПД, идемпотентный webhook, разделение моделей flash / pro
5. **Vibe Coding end-to-end** — Android + Python-сервер + админка собраны как единый релизный цикл (версия, changelog, деплой)
