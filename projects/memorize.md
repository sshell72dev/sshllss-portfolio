# Memorize - Мобильное приложение для заучивания текстов

## 📱 Описание проекта

Мобильное приложение для Android и iOS, помогающее учить наизусть тексты и стихотворения с использованием AI и голосовых технологий.

**Тип проекта:** Мобильное приложение (Android & iOS)  
**Платформы:** Android (Kotlin), iOS (Swift)  
**Архитектура:** MVVM (Model-View-ViewModel)

## 🎯 Основные возможности

- Поиск текстов через AI API
- Загрузка текста из файла (txt и другие текстовые форматы)
- Ввод текста вручную через интерфейс
- Автоматическое разбиение текста на разделы, абзацы и фразы с помощью AI
- Двухэтапное обучение:
  - Первый прогон: бот читает, пользователь повторяет
  - Второй прогон: пользователь говорит первым
- Кумулятивный повтор с начала до текущей позиции
- Распознавание речи и проверка правильности
- Статистика обучения с оценкой
- Поздравление с анимацией при завершении
- Просмотр структуры текста (разделы, абзацы, фразы)

## 🛠 Технологический стек

### Android
- **Kotlin** - основной язык разработки
- **Jetpack Compose** - современный UI фреймворк
- **Room Database** - локальная база данных с DAO Pattern
- **Retrofit** - HTTP клиент для API запросов
- **KSP (Kotlin Symbol Processing)** - обработка аннотаций
- **Coroutines** - асинхронное программирование
- **ViewModel & LiveData** - управление состоянием UI
- **Navigation Component** - навигация между экранами
- **Android TTS** - синтез речи
- **Android Speech Recognition** - распознавание речи

### iOS
- **Swift** - основной язык разработки
- **SwiftUI** - декларативный UI фреймворк
- **SQLite.swift** - работа с базой данных
- **Alamofire** - HTTP клиент для API запросов
- **AVSpeechSynthesizer** - синтез речи
- **Speech Framework** - распознавание речи

### Общие технологии
- **AI API** - интеграция с AI для поиска и обработки текстов
- **REST API** - работа с внешними сервисами
- **JSON** - обработка данных
- **MVVM** - архитектурный паттерн
- **Repository Pattern** - работа с данными

## 📊 Особенности реализации

### Сложные технические решения

1. **Двухэтапная система обучения**
   - Реализация двух проходов с разной логикой
   - Кумулятивный повтор с начала текста
   - Управление состоянием обучения

2. **Интеграция AI для обработки текста**
   - Поиск текстов через AI API
   - Автоматическое разбиение на структурированные части
   - Парсинг JSON ответов от AI

3. **Голосовые технологии**
   - Синхронизация TTS и Speech Recognition
   - Проверка правильности произношения
   - Обработка ошибок распознавания

4. **Кросс-платформенная архитектура**
   - Общая бизнес-логика
   - Нативные UI для каждой платформы
   - Единая структура данных
